# agent-environments

Перенос текущего инженерного окружения Codex с Windows на **macOS**.

**Агент: начни с [START-HERE.md](START-HERE.md).** Установи доступные локальные компоненты. Для каждого отсутствующего аккаунта, ключа или разрешения явно обратись к владельцу. После подключения проверь доступ. Не проси присылать секреты в чат.

## Быстрый старт на Mac

Нужны Git и Node.js 22+. Проверь `git --version` и `node --version`. Если их нет, установи подходящие для Apple Silicon или Intel версии через официальный установщик либо уже установленный Homebrew.

```bash
git clone https://github.com/romanssam/agent-environments.git
cd agent-environments
node scripts/bootstrap.mjs --dry-run
node scripts/bootstrap.mjs --apply
node scripts/doctor.mjs
```

Установщик переносит **42 пользовательских навыка** с ресурсами в `~/.agents/skills`, инструкции и review runner в `CODEX_HOME` (по умолчанию `~/.codex`). Он добавляет Stop hook и сохраняет существующие настройки. Изменённые файлы навыков вызывают конфликт: сначала сравни файлы; `--replace` разрешает замену с резервной копией.

Если существующие `AGENTS.md` или `config.toml` отличаются, они сохраняются. Агент должен вручную объединить правила из `payload/codex/AGENTS.md` и шаблон конфигурации с действующими файлами. Проверяй сообщения Pending manual merge.

## Что включено

| Состав | Где находится |
| --- | --- |
| 42 пользовательских навыка, scripts/references/assets | `payload/agents-skills` |
| Глобальные правила engineering-control, ub-mode, Harness2 и SDD | `payload/codex/AGENTS.md` |
| Независимый review runner, тесты и hooks | `payload/codex/scripts/code-session-review` |
| 5 проектных навыков и 12 ролей inspectionFront | `payload/profiles/inspectionFront` |
| Шаблоны настроек и MCP без секретов | `templates` |
| Источники, версии и SHA-256 | `sources.json`, `manifest.json` |
| Подключение всех аккаунтов | [docs/CONNECTIONS.md](docs/CONNECTIONS.md) |
| Программы, плагины и ограничения ОС | [docs/RUNTIMES.md](docs/RUNTIMES.md) |

Проектный профиль не устанавливается глобально. Для работы с inspectionFront сначала клонируй сам проект и прочитай его актуальные AGENTS.md. Сравни профиль с текущей версией; нужные навыки копируй в его `.agents/skills`, роли — в `.codex/subagents`. Исходники проектов и рабочие задачи сюда не включены.

## Что агент должен запросить

Проверь все строки [CONNECTIONS.md](docs/CONNECTIONS.md). Для отсутствующего подключения попроси владельца выполнить вход, выдать доступ или безопасно настроить локальную переменную. Это касается Codex/OpenAI, GitHub, Figma, Adobe, Pages/Spaces, Sites, Pets, Linear, Notion, Wellsoft и справочника project_handbook.

MCP-шаблон не активирован автоматически. URL пользовательских серверов и значения ключей предоставляет владелец. Установка плагина не подтверждает авторизацию. Доверие к hooks и разрешения macOS выдаются заново через интерфейс приложения.

Системные навыки, браузерные инструменты, генерацию изображений и библиотеки документов предоставляет установленный Codex. Они восстанавливаются штатно по реестру плагинов, а не копированием Windows-кэша. Точная прежняя версия может быть недоступна; агент должен указать различие.

## Проверки и обновление

```bash
npm test
npm run validate
node scripts/doctor.mjs --strict
git pull --ff-only
node scripts/bootstrap.mjs --dry-run
```

`doctor --strict` проверяет Node, Git и целостность установленных навыков. Он не подтверждает вход в аккаунты, доверие к hooks и работу всех внешних сервисов. Их проверяет агент отдельно.

Резервные копии лежат в `CODEX_HOME/backups/<запуск>`. Внутри есть `manifest.json` с исходным назначением и SHA-256 каждого `.bak`. Для отката останови установку, проверь путь и хеш, затем восстанови нужный файл вручную. Новые файлы, которых не было до установки, удаляй только после проверки их принадлежности этому запуску. Автоматического массового отката нет.

Для изолированной пробы: `node scripts/bootstrap.mjs --apply --home /absolute/temporary-home`. Этот параметр не использует действующий CODEX_HOME.

Полный upstream benchmark Harness2 требует **Linux**. Обычная методика навыка работает отдельно. Платные эксперименты требуют отдельного разрешения и бюджета. Orca и Blender требуют собственных локальных интеграций. Crapper/Dryer/Mutator не были доступны при экспорте; их метрики не заявляются.

Этот пакет подготовлен на Windows. Физический Mac и новые аккаунты пока не проверены. CI проверяет код на macOS, Linux и Windows; фактический статус смотри во вкладке Actions.
