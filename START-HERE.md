# Инструкция агенту на новом Mac

1. Прочитай README.md, manifest.json и docs/CONNECTIONS.md. Сопоставь компоненты с текущей версией Codex и архитектурой Mac.
2. Проверь Git, Node 22+, Codex, Python/uv и зависимости нужных навыков. Установи недостающие программы штатным способом. Не копируй Windows-бинарники и внутренние native-pipe настройки.
3. Запусти `node scripts/bootstrap.mjs --dry-run`. Проверь конфликты и пути. Затем выполни `--apply`.
4. Объедини сохранённые существующие AGENTS.md/config.toml с комплектом. Настрой плагины из manifest.json штатно. Читай инструкции соответствующего плагина.
5. Проверь каждое подключение из docs/CONNECTIONS.md. Для каждого отсутствующего аккаунта, ключа и разрешения **явно попроси владельца** выполнить нужное действие. Можно собрать запросы одним списком. Секреты вводятся локально безопасным способом, без чата и Git.
6. Через текущий интерфейс Codex предложи владельцу просмотреть и доверить новые hooks. Для компьютерного управления запроси необходимые macOS-разрешения. Старые trust hashes и cookies не переносить.
7. Запусти `npm test`, `npm run validate` и `node scripts/doctor.mjs --strict`. Проверь реальный запуск review runner в отдельном тестовом репозитории после входа в Codex; запуск моделей использует доступный лимит владельца.
8. По каждому компоненту запиши: установлен, включён, авторизован, проверен. Для пробела укажи точное действие пользователя. Не объявляй полную готовность по одному успешному установщику.

Для работы с продуктовым проектом клонируй его отдельно и прочитай актуальные инструкции. Следуй установленным engineering-control, ub-mode, Harness2 и sdd-quality-gate. Перенос файлов не переносит чаты, рабочие ветки и историю задач.
