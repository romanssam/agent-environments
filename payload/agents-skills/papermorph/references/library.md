# Локальная библиотека учебных материалов

Библиотека сохраняет подготовленные материалы на этом компьютере. Текст обучения, подписи, задания и объяснения должны быть на русском языке. Имена API, код, цитаты и адреса источников можно сохранять в исходном виде.

Скрипт `scripts/library.py` использует только стандартную библиотеку Python. SQLite — локальная база в одном файле. Отдельный сервер базы не нужен.

## Где находятся данные

Папка выбирается в следующем порядке:

1. Параметр `--root` перед именем команды.
2. Переменная окружения `PAPERMORPH_LIBRARY`.
3. Папка `learning-library` внутри `CODEX_HOME`.
4. Папка `~/.codex/learning-library`.

Стандартный путь — `~/.codex/learning-library`; уважай `CODEX_HOME` и `PAPERMORPH_LIBRARY`.

```text
learning-library/
  library.sqlite3
  materials/
    <slug>/
      versions/
        1/
          index.html
          assets/...
        2/...
  .staging/
```

`slug` — постоянный идентификатор материала. Используйте строчные латинские буквы, цифры, дефис или знак подчеркивания. Например: `react-event-loop`. Версии одного материала используют тот же `slug`.

## Подготовка результата

1. Создайте отдельную папку для готовой книги, главы или конспекта. Стандартный путь для результата — `<LIBRARY>/work/<slug>/site/<slug>`.
2. Поместите в нее стартовый файл и все нужные локальные ресурсы.
3. Сохраните русский текст каждой главы в `text/chNN.md` или `text/chNN.json` внутри этой папки.
4. Проверьте русский текст и работу материала.
5. Сохраните папку через `register`.
6. Сообщите пользователю `slug`, номер версии и путь `entry_file` из результата команды.

В текстовые файлы глав включите название, объяснения, текст озвучивания и задания. Используйте авторский учебный текст. Например, первая глава находится в `text/ch01.md`. Эти файлы нужны для поиска по содержанию. Papermorph может формировать пояснения из JavaScript и хранить сценарий озвучивания вне папки сайта. Индекс HTML исключает `script` и `style`, поэтому одного стартового HTML-файла может быть недостаточно. Текстовые файлы глав сохраняются вместе с книгой. Приватные исходные PDF в них не копируются.

Регистрация копирует **все файлы** внутри указанной папки. Скрипт сохраняет относительные пути. Не помещайте в эту папку приватные исходные PDF, секреты, временные файлы и рабочий репозиторий. Исходные документы храните отдельно. Параметр `--source` записывает адрес или описание источника, но не копирует и не загружает его.

Стартовый файл должен находиться внутри папки материала. Ссылки на внешние файлы не превращаются в локальные ресурсы. Символические ссылки и точки подключения Windows отклоняются. Папка результата может находиться внутри `work` библиотеки. Нельзя регистрировать корень библиотеки, папку, которая содержит этот корень, или папки внутри `materials` и `.staging`. Это защищает от повторного копирования снимков и базы в саму библиотеку.

## Команды в PowerShell

Используйте доступный Python 3.9 или новее. На этом компьютере есть встроенный Python:

```powershell
$PapermorphPython = '<WINDOWS_HOME>/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe'
$PapermorphLibraryScript = '<WINDOWS_HOME>/.agents/skills/papermorph/scripts/library.py'

& $PapermorphPython $PapermorphLibraryScript init

& $PapermorphPython $PapermorphLibraryScript register `
  --slug react-event-loop `
  --title 'Цикл событий JavaScript' `
  --path 'D:/Learning/Exports/react-event-loop' `
  --entry index.html `
  --type book `
  --status ready `
  --source 'https://developer.mozilla.org/ru/docs/Web/JavaScript'

& $PapermorphPython $PapermorphLibraryScript list
& $PapermorphPython $PapermorphLibraryScript list --status ready --type book
& $PapermorphPython $PapermorphLibraryScript search 'очередь микрозадач'
& $PapermorphPython $PapermorphLibraryScript show react-event-loop
& $PapermorphPython $PapermorphLibraryScript show react-event-loop --version 1
```

Повторяйте `--source` для нескольких источников. Параметр `--type` принимает `book`, `course`, `chapter` или `notes`. Параметр `--status` принимает `draft` или `ready`. Значения по умолчанию: `book`, `draft`, стартовый файл `index.html`, язык `ru`.

Для конспекта можно указать `--type notes --entry notes.md`. Язык задается параметром `--language ru`. Другие значения отклоняются. Скрипт проверяет метаданные языка. Автор материала отвечает за фактический русский текст.

Команды возвращают JSON в UTF-8. `entry_file` указывает на сохраненный стартовый файл. `created: false` означает, что текущая версия уже содержит такие же файлы и метаданные. `list` и `search` возвращают до 100 материалов. Для другого ограничения используйте `--limit`.

Для отдельной библиотеки укажите путь до команды:

```powershell
& $PapermorphPython $PapermorphLibraryScript --root 'D:/Learning/Library' init
& $PapermorphPython $PapermorphLibraryScript --root 'D:/Learning/Library' list
```

## Версии и поиск

Каждая новая версия содержит полный снимок файлов. Изменение содержимого, названия, статуса, типа, списка источников или стартового файла создает следующую версию. Повторная регистрация текущего содержимого с такими же метаданными не создает дубликат. Изменение только времени файла не создает новую версию.

Предыдущие версии не перезаписываются. SQLite запрещает изменение и удаление строк версий и файлов через триггеры. Копии файлов доступны для чтения как обычные файлы. Не редактируйте их вручную. Для изменения материала отредактируйте рабочую папку и повторите `register`.

База хранит следующие данные:

| Таблица | Данные |
| --- | --- |
| `materials` | `slug`, название, тип, статус, язык, источники, текущая версия и даты |
| `versions` | Неизменяемые метаданные версии, стартовый файл, путь снимка, общий хеш и дата |
| `files` | Относительный путь, размер, SHA-256, извлеченный текст и признак сокращения текста |

SHA-256 — хеш для проверки содержимого файла. Общий хеш версии учитывает пути, размеры, содержимое файлов и метаданные. Порядок обхода файлов детерминирован.

Поиск проверяет метаданные и текст **текущей версии** каждого материала. Он не различает регистр русских и латинских букв. Запрос ищется как подстрока. Историю версий можно просмотреть командой `show`. Поиск по старым версиям не выполняется.

Текст извлекается из HTML, Markdown, TXT и JSON. Содержимое HTML-тегов `script` и `style` не индексируется. Для одного файла читаются первые 2 МиБ. После извлечения сохраняются до 250 000 символов на файл и до 2 000 000 символов на версию. `text_truncated: 1` в списке файлов означает сокращение индекса. Сами файлы копируются полностью. Поиск использует `casefold` и SQLite `LIKE`; расширение FTS не требуется.

## Сохранность данных

Регистрация сначала создает временный снимок в `.staging`. Затем она переносит готовую папку на место одной операцией и записывает данные в транзакции SQLite. При обычной ошибке скрипт отменяет транзакцию и удаляет свой незарегистрированный снимок. Предыдущие версии сохраняются.

Принудительное завершение процесса или отключение питания между переносом папки и записью базы может оставить незарегистрированную папку. Она не появляется в `list` и `search`. Следующая регистрация не перезаписывает такую папку и выбирает свободный номер. Незавершенный временный снимок также может остаться в `.staging`. Скрипт не удаляет такие папки автоматически, чтобы не затронуть параллельную регистрацию.

Для резервной копии остановите регистрацию и скопируйте всю папку библиотеки. Одного файла SQLite недостаточно: в нем нет бинарных ресурсов книги. Автоматической синхронизации между компьютерами нет.

## Что означает статус и где хранится прогресс

`draft` означает, что материал сохранен как черновик. `ready` означает, что автор проверил его и считает готовым. Скрипт не проверяет качество текста, анимации, звук и доступность ссылок. Эти проверки выполняются при создании материала.

Прогресс чтения и упражнений движок Papermorph хранит в `localStorage` браузера. Он относится к конкретному браузеру и адресу книги. Эта библиотека хранит материалы, метаданные и версии. Она не переносит прогресс из `localStorage` в SQLite и не синхронизирует его между браузерами.
