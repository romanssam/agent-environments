# Phase boundaries

At the end of exploration, a ticket, or verification, decide whether to continue from current evidence or save a checkpoint before a supported context transition.

1. Continue while the next step is clear and current evidence fits; primary evidence is preferable to repeatedly reconstructed summaries.
2. For a phase/session transition, use handoff to save the goal, contracts, decisions, checkout state, checks, and next step in the global task directory. Link detailed evidence instead of copying it.
3. Delegate an independent bounded check only when current instructions allow it and useful work can continue locally.
4. Use actual context telemetry when available. Repeated rediscovery, conflicting stale notes, and a widening task are reasons to checkpoint and narrow the next step, not proof of a numerical intelligence threshold.
5. Clear/compact/new-session actions require supported host capabilities and the relevant user authorization. Writing their names in a shell does not perform them. If unavailable, keep a concise checkpoint and continue within the existing task.

A saved handoff is portable data. A host-level task transfer or synchronization is a separate operation.
