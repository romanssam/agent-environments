# Работа с этим репозиторием

Для восстановления окружения на новом компьютере сначала прочитай START-HERE.md и README.md. Подключения и обращения к владельцу определены в docs/CONNECTIONS.md.

Для изменения пакета используй engineering-control и текущие пользовательские правила согласования. Не редактируй действующее домашнее окружение ради проверки: используй bootstrap --home с отдельной временной папкой.

Сохраняй происхождение и лицензии навыков. При изменении payload обнови SHA-256 в manifest.json. Запусти npm test и npm run validate. Код пиши с понятными именами без поясняющих комментариев.

Аккаунты, секреты, cookies, личную историю, сессии, доверие hooks и app-managed бинарники сохраняй за пределами Git. Если на новом компьютере отсутствует подключение, явно попроси владельца пройти вход или безопасно настроить локальный доступ.
